# My Blog

스프링부트4 책을 보고 학습하는 블로그 프로젝트입니다.

## 📌 프로젝트 소개
Spring Boot + Gradle 기반의 블로그 웹 애플리케이션입니다.

## 🛠 기술 스택

### Backend
- **Java** 25
- **Spring Boot** 4.1.0
- **Spring Data JPA**
- **Spring AI**
- **Gradle** (Kotlin DSL 또는 Groovy)

### Database
- MySQL / H2 (개발용)

### View
- Thymeleaf (서버사이드 렌더링)

### 기타
- Spring Security
- Lombok
- Swagger / OpenAPI
